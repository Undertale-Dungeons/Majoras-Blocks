# Contributing

Thanks for your interest in contributing to Majora's Block.

The project is in early development, so contribution workflows and technical conventions are still being established.

## Before making changes

1. Open an issue to describe the bug, proposal, or feature.
2. Wait for discussion before starting substantial work.
3. Keep changes focused and avoid unrelated refactoring.
4. Do not submit copyrighted game assets, ripped textures, or extracted music.
5. Include clear testing notes with your pull request.

## Pull requests

A useful pull request should include:

- A concise summary of the change.
- The reason for the change.
- Relevant screenshots or logs, when applicable.
- The Minecraft and Fabric versions used for testing.
- Any known limitations or follow-up work.

## Code of conduct

Be respectful, constructive, and welcoming. Harassment, personal attacks, and discriminatory conduct are not acceptable.

More detailed development and style guidelines will be added as the codebase takes shape.
